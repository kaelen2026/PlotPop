# ADR-006 对象存储资产不可变

- 选了什么：`asset` 记录不可变，替换文件即创建新 Asset。镜头重生成产生新的候选 Shot Version，旧版本保留到用户主动删除。已完成的导出保存当时采用的全部版本引用。

- 否掉了什么 / 为什么：
  - **原地覆盖同一对象存储 Key**。已导出的成片会随之静默变化，可复现性丢失；CDN 缓存也难以准确失效。对一个按集连载的产品，"上周导出的那一集现在不一样了"是不可接受的。
  - **只保留最新版本、生成后删旧的**。用户需要在候选版本之间比较和回退，这是逐镜头重生成工作流的核心；删了就回不去，只能重新付费生成。

- 当时的前提：逐镜头重生成是核心工作流；对象存储成本远低于重新生成成本；原始素材、中间产物和导出使用独立路径与生命周期规则。

- 已知代价：存储持续增长，必须为原始素材、中间产物、失败产物和最终导出分别定义保留周期；上传成功但数据库回写失败的孤立对象需要 Reconciler 按校验和接管或清理。

- 何时重审：存储与带宽成本进入单位经济模型的显著项；或保留周期需要按用户套餐区分。
